# 3D Digital Pipeline Tool

Interactive real-time 3D digital pipeline and animation tooling prototype inspired by production workflows used in VFX and themed entertainment environments.

## Features

* Real-time WebGL viewport rendering
* Rigging and IK/FK controls
* Animation timeline system
* Asset browser and pipeline status tracking
* Multi-format export simulation (FBX, OBJ, USD, glTF)
* Maya-inspired tooling workflow UI

## Technologies

* HTML5
* CSS3
* JavaScript
* WebGL
